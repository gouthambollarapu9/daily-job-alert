# Job Search

1. Confirm target roles, locations, seniority, and work authorization from the request and verified profile.
2. Check each opening on an employer or recruiter page when possible.
3. Record its link, location, work setup, and any eligibility constraints.
4. Rank by fit using specific evidence from the resume and portfolio.
5. Tailor the summary, bullets, and work samples to the posting.
6. Flag unknown application answers and use only verified experience, dates, metrics, and credentials.
7. Submit only when authorized and verify the application receipt.
