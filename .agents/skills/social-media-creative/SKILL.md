# Social Media Creative

1. Match the format to the message and platform.
2. Give each carousel slide one job and put the main idea on the opening slide or frame.
3. Draft on-art text and captions separately.
4. Check crop, interface overlays, text hierarchy, and mobile readability.
5. For bilingual work, review natural wording and right-to-left layout.
6. Preserve facial identity and structure in reference-based visuals.
